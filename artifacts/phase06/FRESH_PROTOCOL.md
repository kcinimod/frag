# Frozen Phase 6 SEC acceptance protocol

Use the independently sealed issue #43 cohort after the issue #42
development gate passes. Export production at
`208cca1e410a0811cba600ad93753b53b42cc43a`. The production source and lockfile
match the development gate. Use the same Python, dependencies, Qwen2.5-0.5B
weights, llama.cpp runtime, retrieval, generation and local planner port
recorded in the gate baseline. Freeze all executable evaluation code and the
receipt digests before granting the runner access to the inputs.

Run the 15 cases in manifest order. Ingest the original filings through the
public CLI. For each case, launch a fresh pinned planner, wait for health and
time the first request including opening every cited endpoint. Repeat the
same question immediately for the warm pass. Time intake and planner startup
separately. Measure Windows process peak working sets and sample device-wide
VRAM using the same procedure as Phase 5. Replay both passes from records
against a fresh ingestion with socket connections and resolution blocked.
Require exact result and opened citation-set equality for every case.

Keep the expected archive outside the runner workspace. Verify both seals
and use the separately reviewed amounts, period cells, statement and row
spans, original note spans, and comparison references. A cited amount must
open on its original revenue cell and fiscal column with the reviewed
currency and scale. An absence claim requires every independently reviewed
fiscal header. Audit extraction across all original observations and count
reusable verification separately, requiring original inline context and
currency corroboration. Score each answer, trace, citation, abstention and
any returned partial evidence. An answerable case can remain incomplete when
its gap accurately describes the intake or downstream processing. A
grounded expected abstention requires its independently reviewed reason
and any required companion operands or period evidence.

Each pass must score at least 11 of 12 supported numeric answers, 3 of 3
grounded abstentions, and 15 of 15 exact result and citation replays. Any
wrong number, unsupported claim or citation, contradicted abstention, or
replay mismatch blocks acceptance. Preserve both pass records and compare
with the historical Phase 5 holdout metrics as a separate cohort.
